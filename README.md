# Ringo 实验室 · 使用说明

本版本仅支持 **Ringo**，包含设备连接、固件烧录、Ringo 实验室和设置。随包提供 **`ringo-v1-2.0.2.public_dev.zip`** 固件。请按下面的顺序先升级固件，再使用实验室。

这是 Python 源码发行包，需要 Python 3.12+、uv、图形桌面和系统蓝牙权限。首次安装依赖需要联网，不需要下载识别模型。

## 一、先升级固件

### 1. 安装并启动工作台

解压整个压缩包，打开终端，进入包含 `pyproject.toml` 的目录，执行：

```sh
uv sync --locked
uv run --locked ring-studio
```

若终端提示找不到 `uv`，可以先执行 `python -m pip install uv`；有多个 Python 环境时，请确认使用 Python 3.12 或更新版本。

macOS 弹出蓝牙权限请求时选择允许。其他系统也需要打开蓝牙并授予程序访问权限。关闭正在连接同一枚戒指的其他桌面工具、手机应用或 BLE 调试器。

### 2. 连接要更新的 Ringo

1. 打开左侧「设备」，点击「扫描设备」。
2. 按名称和地址找到目标 Ringo，点击「连接」。
3. 确认设备显示「已连接」。同时发现多枚戒指时，核对地址，避免选错设备。

### 3. 选择固件并开始烧录

1. 打开左侧「固件烧录」。
2. 在「戒指」下拉框选择刚连接的 Ringo。
3. 在「目标固件版本」选择 **`2.0.2 · public_dev`**。
4. 结束正在进行的录制、同步和实验室控制操作，再点击「开始烧录」。

固件已放在 `firmware_release/`，无需手动解压内部固件 ZIP。列表未显示版本时，点击「刷新版本」。不要将本固件用于 R1 或 BCL；程序也会在烧录前读取设备 INFO，再次检查类型。

### 4. 等待更新完成

界面依次显示：**检查设备 → 上传固件 → 重启设备 → 验证版本**。

保持戒指有电、靠近电脑；重启期间蓝牙短暂断开属于正常现象。上传阶段可以「取消上传」，重启和验证阶段不能取消或退出。**进度到 100% 只表示文件传完，需等待「更新完成」及版本验证通过。**

成功后程序会重新连接并恢复 IMU。到「设备」页确认固件版本为 **2.0.2**；版本文字可能带构建后缀。手势、PPG 和麦克风不会自动恢复，请在实验室中按需开启。

如果提示验证超时或重连失败：先回「设备」页重新扫描、连接并查看实际版本。版本仍旧或设备无法恢复时，请保留完整报错再排查，不要仅凭上传进度判断成功。固件烧录不需要手动强制确认 MCUboot 镜像。

## 二、使用 Ringo 实验室

在「设备」页连接 Ringo 后，打开左侧「Ringo 实验室」，在顶部下拉框选择已连接的戒指。实验室本身不扫描或管理蓝牙连接；切换设备只改变当前查看和单设备录制的目标。

### IMU 波形

连接成功后自动启动 200 Hz 六轴 IMU。也可点击「IMU 开」重新启动，点击「IMU 停」停止。

- 加速度界面单位为 **m/s²**，角速度界面单位为 **°/s**。
- 波形显示最近约 3 秒数据，使用设备原始轴向。
- 无波形时先确认设备连接；查看页面的错误信息。充电状态或其他设备功能占用传感器，可能导致采集不能启动。

### PPG

按需点击「PPG 绿光」「PPG 红光」或「PPG 红外」，观察对应原始波形；点击「PPG 停」停止。

红光采集模式会同时启用红外，模式切换以设备实际收到的数据为准。页面显示的是原始传感器波形。

### 麦克风、LED 和按钮

- 「麦克风开 / 麦克风停」控制实时音频流。
- 「LED 开 / LED 关」发送灯控请求；固件没有灯状态确认应答。
- 「按钮事件」显示最近 50 条事件，可在列表中滚动查看。

应用支持 ADPCM 与 Opus 音频。ADPCM 无需额外音频库；Opus 解码需要系统 `libopus`。macOS 可用 `brew install opus` 安装。页面提示缺少解码库时，请先安装对应库再重启程序。

## 三、保存数据

### 保存当前戒指的 IMU

点击「开始录制 IMU」，结束时点击「结束录制 IMU」。保存：

- `ringo-imu-*.h5`：六轴数据、设备时间戳等。
- 同名 `.meta.json`：帧数与完整性信息。

结束录制后波形继续显示。HDF5 中的加速度单位为 m/s²，角速度单位为 **rad/s**，与界面的 °/s 不同。

### 保存当前戒指的音频

点击「开始录音」，结束时点击「结束录音」。程序会启动麦克风并保存 **16 kHz、单声道、16-bit PCM WAV**，文件名为 `ringo-audio-*.wav`。这是电脑接收的实时音频，不是戒指 Flash 中的历史录音。

### 保存全部已连接 Ringo 的原始数据

点击「全量录制」，结束时点击「停止全量录制」。保存 `ringo-*.jsonl`，包括原始 BLE RX/TX、解码记录及接收到的音频数据。此操作覆盖**全部已连接的 Ringo**，而单独的 IMU 录制和录音只针对当前选择的戒指。

文件默认保存在本项目的 **`data/`** 目录。点击「打开目录」查看；停止后确认页面显示保存结果。断连、丢块、写盘失败或异常退出可能造成文件不完整。
